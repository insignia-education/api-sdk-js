# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

**`AGENTS.md`** (same directory) is the canonical, single source of guidance for this repo — read
it first. It covers the project status, versioning rules, structure, conventions, testing coverage
requirements, the i18n rule, the API ↔ SDK sync rule, the version-bump/publish workflow, the
"Never do" list, working style, git policy, and communication style. Deeper supporting material
(deployment mechanics, research order) lives under `.ai/docs/` and `.ai/guidelines/`, linked from
`AGENTS.md`.

Nothing in `AGENTS.md` is repeated here. This file exists only for guidance specific to the Claude
Code tool itself — there is currently none beyond this pointer.
